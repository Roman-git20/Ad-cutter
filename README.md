# Ad Cutter

Приложение для автоматического вырезания рекламных пауз из видеозаписей
по факту исчезновения логотипа телеканала.

---

## Возможности

- Загрузка видео (MP4, AVI, MKV, MOV) и образца логотипа (PNG, JPG).
- Интерактивное выделение области поиска (ROI) на кадре.
- Детекция логотипа методом Template Matching (OpenCV).
- Настройка порога схожести, минимальной длительности паузы,
  шага проверки кадров.
- Визуализация: график схожести и таблица найденных пауз.
- Нарезка видео с удалением рекламы.
- Отчёт в формате JSON с таймкодами.
- Скачивание результата через веб-интерфейс.

## Запуск через Docker

```bash

```

Открыть в браузере: `http://localhost:8080`

Для сохранения результатов на хост-машине:

## Специфика загрузки данных

### Входные данные

- **Видео** — MP4, AVI, MKV, MOV. Любое разрешение, любой FPS.
- **Образец логотипа** — PNG, JPG, JPEG. Рекомендуется создавать образец
  непосредственно из кадра видео (Способ 1) — это гарантирует
  попиксельное соответствие с содержимым видео и решает проблему
  несовпадения размеров/качества при загрузке готового файла.

### Ограничения входных данных

- Видео должно содержать логотип телеканала в **статичном** положении
  (одно и то же место в каждом кадре).
- Логотип не должен менять размер или цвет между кадрами.
- Имена файлов рекомендуется использовать латиницей
  (проблемы с кириллицей в некоторых системных вызовах OpenCV).

## Порядок работы

1. Загрузить видео.
2. Указать секунду с видимым логотипом и нажать «Показать кадр».
3. Выделить логотип мышью и нажать «Сохранить выделение как образец» —
   область поиска (ROI) построится автоматически (таким образом решена 
   проблема попиксельного несоответствия загружаемого логотипа с имеющимся в видео). 
4. Настроить порог схожести, минимальную длительность паузы,
   шаг проверки кадров.
5. Нажать «Анализировать видео» — появится график и таблица пауз.
6. Нажать «Вырезать рекламу» и скачать итоговое видео и отчёт.

---

## Принцип работы

Для каждого проверяемого кадра из области ROI вырезается фрагмент
и сравнивается с образцом логотипа через `cv2.matchTemplate`
с метрикой `TM_CCOEFF_NORMED`. Метрика возвращает значение от -1.0
до 1.0. Если значение ниже порога — логотип считается отсутствующим,
интервал помечается как рекламная пауза.

---

## Ограничения

- Логотип должен быть статичным и находиться в одном месте кадра.
- Заставки, изменяющие логотип, могут быть ошибочно классифицированы
  как реклама.
- Рекомендуется использовать латинские имена файлов.
